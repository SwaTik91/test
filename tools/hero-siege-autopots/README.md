# Hero Siege — автопоты (AutoHotkey v2)

Локальный помощник: смотрит HP/MP-полоски по цвету пикселей и жмёт клавиши банок, **только пока активно окно Hero Siege**. Это не инжект и не работа с памятью игры.

Автоматизация может нарушать правила игры — используй на свой риск.

## Что нужно

1. [AutoHotkey v2](https://www.autohotkey.com/) (не v1).
2. В игре повесь банки на клавиши скрипта:
   - по умолчанию **1** — HP, **2** — MP
   - несколько слотов HP: в настройках укажи `1,2,3` — если банка не помогла два раза, скрипт возьмёт следующий слот

## Запуск

1. Двойной клик по `HeroSiegeAutoPots.ahk`.
2. Если игра запущена **от администратора**, скрипт тоже запускай от администратора (иначе нажатия могут не доходить).
3. Окно Hero Siege в фокусе.

## Калибровка (обязательно для HP)

Делай на **полном** здоровье, в бою/локации, когда HUD виден.

1. Наведи курсор на **левый** край красной HP-полоски, нажми **F6**, затем ещё раз **F6**.
2. Наведи на **правый** край той же полоски, снова **F6**.
3. Для маны то же самое на синей полоске клавишей **F7** (можно не калибровать, если MP-банки не нужны).

Координаты пишутся в `autopots.ini` как доли окна — смена разрешения обычно не сбивает калибровку, но после смены режима окна лучше пройти F6 ещё раз.

## Клавиши

| Клавиша    | Действие                                      |
|------------|-----------------------------------------------|
| **F8**     | Вкл / выкл автопотов                          |
| **F6**     | Калибровка HP                                 |
| **F7**     | Калибровка MP                                 |
| **F9**     | Цвет и координаты под курсором (отладка)      |
| **F10**    | Порог %, клавиши банок, кулдаун               |
| **Shift+Esc** | Выход                                      |

Пока автопоты выключены или окно игры не в фокусе — ничего не жмётся.

## Если пьёт слишком рано / слишком поздно

- Порог в **F10**: меньше % — пьёт позже, ближе к смерти.
- Допуск цвета (30–150): если полоска «мигает» и банки спамятся — уменьши; если не видит HP — увеличь.
- **F9** на заполненной полоске: должен быть красный (HP) или синий (MP), не чёрный `0x000000`. Если всегда чёрный — в `autopots.ini` оставь `pixelMode=Slow` или попробуй пустое значение.

## Аварийный стоп

**F8** выключает цикл. **Shift+Esc** закрывает скрипт. В трее тоже есть выход.
