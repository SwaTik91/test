# Hero Siege — автопоты (AutoHotkey v2)

Локальный помощник: смотрит HP/MP-полоски по цвету пикселей и жмёт клавиши банок, **только пока активно окно Hero Siege**. Это не инжект и не работа с памятью игры.

Автоматизация может нарушать правила игры — используй на свой риск.

## Что нужно

1. [AutoHotkey v2](https://www.autohotkey.com/) (не v1).
2. В игре повесь банки на клавиши скрипта:
   - по умолчанию **1** — HP, **2** — MP
   - несколько слотов HP: в настройках укажи `1,2,3` — если банка не помогла два раза, скрипт возьмёт следующий слот

## Запуск

1. Двойной клик по `HeroSiegeAutoPots.ahk`.
2. Если игра запущена **от администратора**, скрипт тоже запускай от администратора (иначе нажатия могут не доходить).
3. Окно Hero Siege в фокусе.

## Калибровка HP

Кликни по окну игры (здоровье полное) и нажми **F6**. Скрипт **сам ищет** красную полоску в верхнем левом углу.

Белую подсказку на HP больше не рисует: она перекрывала полоску и давала цвет вроде `0xDDE3E9` вместо красного.

Если автопоиск не сработал — наведи на **красную заливку** (не золотую рамку и не белые цифры) и нажми F6 два раза: левее и правее середины полоски.

**F7** — то же для синей маны. **F8** — включить автопоты.

## Клавиши

| Клавиша    | Действие                                      |
|------------|-----------------------------------------------|
| **F8**     | Вкл / выкл автопотов                          |
| **F6**     | Калибровка HP                                 |
| **F7**     | Калибровка MP                                 |
| **F9**     | Цвет и координаты под курсором (отладка)      |
| **F10**    | Порог %, клавиши банок, кулдаун               |
| **F11**    | Оверлей в другой угол                         |
| **Shift+Esc** | Выход                                      |

Пока автопоты выключены или окно игры не в фокусе — ничего не жмётся.

## Цвет везде 3F3949

Это **не защита**. GDI не умеет читать DirectX-кадр Hero Siege, поэтому `screen` / `window` / `alt` всегда отдают заливку окна `0x3F3949`.

Скрипт читает кадр через **DXGI Desktop Duplication** (тот же принцип, что Display Capture в OBS).

1. Скачай новый `.ahk`. Старый `autopots.ini` сам переключится на `dxgi`.
2. Если DXGI не стартует — закрой OBS, Xbox Game Bar, Discord overlay и запусти скрипт снова.
3. Наведи на красную HP и нажми **F9**. Смотри строку **`dxgi`** (подсказка теперь внизу экрана, не на полоске). Там должен быть красный, а `screen` может остаться `3F3949`.
4. Потом калибровка **F6**.

## Если пьёт слишком рано / слишком поздно

- Порог в **F10**: меньше % — пьёт позже, ближе к смерти.
- Допуск цвета (30–150): если полоска «мигает» и банки спамятся — уменьши; если не видит HP — увеличь.
- **F9** на заполненной полоске: метод `screen` должен показать красный (HP) или синий (MP).

## Аварийный стоп

**F8** выключает цикл. **Shift+Esc** закрывает скрипт. В трее тоже есть выход.
