# Hero Siege — фарм по миникарте (Python)

Ищет путь **A\*** по снимку миникарты: белые линии = стены, тёмное = туман, цветное = пол. Жмёт WASD. Это не чтение памяти.

Банки по-прежнему в `HeroSiegeAutoPots.ahk` (F6/F8). **F4 в AHK не включай** — иначе два скрипта будут драться за WASD.

Автоматизация может нарушать правила игры.

## Windows

```text
pip install -r requirements.txt
python farm.py
```

С отладкой (окно сетки: белое стена, чёрное туман, жёлтый путь):

```text
python farm.py --debug
```

1. Игра в фокусе, данж, миникарта **M**.
2. Наведи на левый верхний угол самой карты → **F3**.
3. Правый нижний → **F3**.
4. **F4** — ходьба. Ещё раз F4 — стоп. **Shift+Esc** — выход.
5. AHK: только поты (F8).

Координаты карты пишутся в `farm.json` рядом со скриптом.

`dxcam` — тот же DXGI, что в AHK. Если не ставится, останется `mss` (на DirectX часто слепой).
