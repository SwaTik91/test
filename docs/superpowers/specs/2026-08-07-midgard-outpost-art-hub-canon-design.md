# Мидгард: Аванпост — канон арта и хаба (дизайн)

Связано с: `2026-08-07-midgard-outpost-design.md`, арт-волны 1–2, store listing.

## 1. Цель

Зафиксировать выбранный визуальный канон (RO-арт + плоский мобильный UI хаба) и заменить текущие спрайты/фоны/хаб-экраны так, чтобы телефонный playtest совпадал с утверждёнными макетами.

## 2. Визуальные решения

| Параметр | Выбор |
|----------|--------|
| Арт персонажей/мобов/фонов | Классический **Ragnarok Online** (Gravity 2.5D), не инди-пиксель и не реалистичный 3D |
| UI хаба и HUD-кнопки | **Мобильный flat** (скругления, slate/amber), не окна Windows/RO-хром |
| Каркас хаба | Вариант **E**: справа плоская панель-навигация, слева/центр RO-арт |
| Эталон вкладки | **Умения** (`hub-skills-canon`) — все вкладки в том же каркасе |
| Забег (поля/лес) | Композиция **как в Mario**: небо + ровная полоса земли; арт RO |
| Язык UI | Только русский |

## 4. Хаб UI (каркас E)

### 4.1 Оболочка

- Landscape SafeArea.
- Слева/центр: `town_bg` + портрет/спрайт текущего класса (RO-арт).
- Справа: плоская тёмная панель (~35–40% ширины), скругление ~16, вертикальный список:
  - Главная  
  - Статы  
  - Умения ← визуальный эталон  
  - Магазин  
  - кнопка **В поля** (amber, внизу панели)
- Без Material AppBar на главных вкладках; back внутри панели или жест/системный back.

### 4.2 Вкладки (содержание)

| Вкладка | Содержание |
|---------|------------|
| Главная | Base/Job, золото, кристаллы, имя класса |
| Статы | STR…LUK, «+», очки статов |
| Умения | Список умений класса, ранги, очки умений (эталон) |
| Магазин | Каталог IAP, Купить |
| В поля | Подтверждение → `RunScreen` |

Навигация: один `HubShell` + переключение body; не отдельные Scaffold с разными стилями.

### 4.3 Создание героя

Тот же visual language: город + flat-панель выбора класса с иконками/превью утверждённых героев.

## 5. Забег

- Фоны fields/forest в Mario-композиции; `ground_tile` под ногами.
- Мобы из канона; боссы чередуются (demon → spider → undead → golem → …).
- Снаряды и кнопки прыжка/ульта из канона.
- HUD: компактный (уже чинили overflow); не перекрывать >~30% высоты.

## 6. Технические ограничения

- Flame `Sprite.load` — пути **без** двойного `assets/images/` (уже исправлено).
- HUD только после `isRunReady`.
- PNG с прозрачностью где нужно; scale nearest-neighbor.
- Обработка больших AI-исходников: при импорте ресайз до игровых размеров (герои ~64–128, боссы ~96–160, фоны под viewport).

## 7. Вне скоупа этого прохода

- Полная перерисовка всех кадров анимации волны 2 под новый стиль (можно follow-up).
- Новые классы / новые биомы.
- Живые IAP SDK.

## 8. Критерии приёмки

1. Хаб визуально соответствует каркасу E / эталону Умения.
2. В игре отображаются утверждённые герои, мобы, 4 босса, сундук, фоны MR3/FR3, снаряды, кнопки.
3. `flutter test` зелёный; playtest APK без LateError и с читаемым хабом.
4. Канон-файлы лежат в репо (`docs/superpowers/art-canon/` или `midgard_outpost/assets/...`).
