# Мидгард: Аванпост — дизайн-спека (MVP)

## 1. Обзор

**Мидгард: Аванпост** — пиксельный 2D side-scroller в духе светлого фэнтези Ragnarok Online. Игрок выбирает класс, уходит из города в бесконечные поля, бежит и прыгает, убивает мобов и боссов, качает героя навсегда и собирает временные усиления забега.

| Параметр | Решение |
|----------|---------|
| Жанр | Экшен / аркада, side-scroller |
| Камера | 2D вид сбоку |
| Стиль | Пиксель-арт, светлое фэнтези (RO-настроение) |
| Платформа | Flutter + Flame |
| Ориентация | Альбомная (landscape) |
| Язык MVP | Только русский |
| Сторы | Huawei App Gallery, RuStore |
| Монетизация | Бесплатно + IAP (кристаллы, ускорители) |
| Сейв | Облачный сейв в MVP; мультиплеер — позже |

## 2. Основной цикл

1. Город «Аванпост» → распределение статов / умений, магазин, старт забега.
2. Забег: бег, прыжок, авто-бой, ульт по кнопке.
3. Награды в забеге: золото, Base/Job опыт, сундуки, дроп, временный опыт забега.
4. Смерть → итоги → возврат в город.
5. Мета-прогресс сохраняется; временные улучшения забега сгорают.

Длина сессии растёт с прокачкой персонажа: сначала короткие вылазки, позже длиннее и сложнее.

## 3. Прогрессия

### 3.1 Base Level (навсегда)

Повышение Base Level даёт очки характеристик. Распределение вручную в городе, как в классическом RO:

- **STR** — физический урон  
- **AGI** — скорость атаки / лёгкий dodge-эффект  
- **VIT** — HP / физическая защита  
- **INT** — магический урон / SP  
- **DEX** — точность / урон лука / стабильность  
- **LUK** — шанс и сила крита  

### 3.2 Job Level (навсегда)

Повышение Job Level даёт очки умений класса. Ранги умений распределяются вручную в городе. В MVP все умения класса доступны с низкого ранга без жёстких пререквизитов (гейты дерева — post-MVP).

### 3.3 Временные улучшения забега

Не выдаются от обычного Level Up. Источники:

1. **Основное:** сундуки; дроп с мобов/боссов с шансом %.  
2. **Дополнительно:** отдельный «временный опыт» забега — реже открывает выбор усиления.

На экране выбора — **3 карты**, игрок берёт одну. После смерти забега все временные улучшения сбрасываются.

В пул выбора входят:

- общие усиления забега (раздел 5);  
- усиления умений **текущего** класса (раздел 6).

## 4. Бой и управление

### 4.1 Управление (landscape)

- Камера и прогресс забега движутся вправо по бесконечной карте  
- Игрок управляет **горизонтальным смещением** (вперёд/чуть назад в пределах разумного), **прыжком** и **ультом**  
- Ультимейт — по кнопке (кулдаун; точный ресурс ульта калибруется на прототипе)  
- Остальные умения и базовая атака — **автоматически** (КД, дистанция, приоритет целей)

### 4.2 Мир забега

- Бесконечная карта вправо  
- Платформы, ямы, препятствия  
- Волны мобов  
- Боссы как вехи сложности и награды  
- Смена фонов/биомов по дистанции (поля → лес и т.д.)

### 4.3 Ресурсы в бою

- HP, SP (авто-скиллы тратят SP)  
- Ульт на отдельном кулдауне (уточняется балансом)  
- Временный опыт забега (отдельный параметр UI)

## 5. Классы и умения (город / Job)

### 5.1 Лучник

| Умение | Тип | Эффект |
|--------|-----|--------|
| Двойная стрела | авто | Две стрелы; урон от DEX/STR |

| Ловушка | авто | Ставится под врагом, замедление |
| Глаз орла | пассивка | +CRIT / +точность от LUK/DEX |
| Град стрел | ульт | Залп по площади впереди |

### 5.2 Маг

| Умение | Тип | Эффект |
|--------|-----|--------|
| Огненный шар | авто | Базовый маг. снаряд (INT) |
| Мороз | авто | Замедляет группу |
| Молния | авто | Бьёт приоритетную/дальнюю цель |
| Медитация | пассивка | Реген SP / сила маг. крита |
| Метеор | ульт | Большой AoE, долгий КД |

### 5.3 Паладин

| Умение | Тип | Эффект |
|--------|-----|--------|
| Удар щитом | авто | Ближний стан / нокбек |

| Стойкость | пассивка | +HP / защита от VIT |
| Гнев небес | ульт | Удар вокруг + щит на короткое время |

## 6. Временные улучшения умений (только забег)

По **3 улучшения на каждое умение**. В выбор попадают только умения текущего класса.

### 6.1 Лучник

**Двойная стрела:** Тройная тетива (шанс 3-й стрелы); Тяжёлые наконечники (+% урона умения); Скорострел (−КД).

**Ветряная стрела:** Шквал (+дальность); Отбрасывающая волна (сильнее push); Режущий ветер (+% урона + лёгкий DoT).

**Ловушка:** Шипастая ловушка (+урон); Клейкая смола (дольше slow); Двойная установка (2 ловушки за каст).

**Глаз орла:** Ястребиный фокус (+CRIT); Снайперский глаз (+точность / игнор части защиты); Охотничий инстинкт (+aspd при HP врага &lt; 50%).

**Град стрел:** Ливень (больше стрел / шире AoE); Бронебойный град (+% урона ульта); Быстрый колчан (−КД ульта).

### 6.2 Маг

**Огненный шар:** Взрывной шар (AoE при попадании); Белый жар (+% урона); Цепной жар (шанс доп. шара во 2-ю цель).

**Мороз:** Вечная мерзлота (дольше slow); Ледяные осколки (+урон); Морозная волна (шире зона).

**Молния:** Грозовой прицел (приоритет сильной цели); Разряд (шанс второго удара); Перегруз (+% урона, выше расход SP).

**Медитация:** Глубокий транс (+реген SP); Ясность (+маг. крит); Экономия маны (−стоимость авто-скиллов).

**Метеор:** Каменный дождь (больше метеоритов); Плавящий удар (+% урона); Быстрый ритуал (−КД ульта).

### 6.3 Паладин

**Удар щитом:** Оглушающий край (дольше стан); Таран (сильнее нокбек + % урона); Серия щитом (−КД).

**Святой удар:** Благодать (+heal); Кара (+% урона); Разящий свет (шанс holy DoT).

**Аура защиты:** Крепость (сильнее −входящий урон); Долгая аура (дольше длительность); Отражение (% урона врагам в ауре).

**Стойкость:** Железная воля (+макс. HP); Несокрушимость (+защита); Вторая кожа (короткий −урон при получении хита).

**Гнев небес:** Расширение кары (больше радиус); Небесный щит (щит крепче/дольше); Скорый гнев (−КД ульта).

## 7. Общий пул временных улучшений забега

### Оффенс

1. Острые наконечники — +% физ. урона  
2. Раскалённая магия — +% маг. урона  
3. Кровожадность — вампиризм %  
4. Двойной выстрел — шанс повторить атаку/скилл  
5. Критическая удача — +CRIT  
6. Бронебой — −защита врагов  

### Защита

7. Вторая жизнь — один раз не умереть (до 1 HP)  
8. Каменный панцирь — +макс. HP  
9. Регенерация — хил со временем  
10. Шипы — % урона атакующим вблизи  
11. Прыжок-щит — короткая неуязвимость после прыжка  

### Утилита

12. Ускорение — +скорость бега  
13. Лёгкие сапоги — выше/дальше прыжок  
14. Жадность — +золото и шанс сундука  
15. Мудрость новичка — +множитель врем. опыта  
16. Заряд ульта — −КД ульта  

### Редкие

17. Тотем силы — все статы +N только в забеге  
18. Знак босса — следующий босс слабее / больше награды  

Редкие карты реже попадают в выбор из трёх.

## 8. Город (хаб) MVP

Одна площадь «Аванпост»:

- Один слот героя в MVP: класс выбирается при создании и далее прокачивается (смена класса / доп. слоты — post-MVP)  
- Экран статов (Base Level)  
- Экран умений (Job Level)  
- Кнопка «В поля»  
- Магазин IAP  

**Post-MVP город:** несколько районов, квесты NPC, крафт.

## 9. Экономика и IAP

| Валюта | Тип | Источник | Траты |
|--------|-----|----------|-------|
| Золото | мягкая | забеги | мелкие расходы / расходники (минимум в MVP) |
| Кристаллы | премиум | IAP | ускорители и премиум-покупки |

**IAP MVP:**

- паки кристаллов;  
- ускорители: буст Base/Job опыта, буст дропа сундуков/усилений, старт забега с небольшим баффом.

Скины / косметика — не в MVP.

## 10. Техническая архитектура

Рекомендуемый подход: **город = Flutter UI**, **забег = Flame**.

### Модули

1. `hub` — город и навигация  
2. `progress` — Base/Job, статы, ранги умений, валюты  
3. `run` — Flame-сессия, мобы, авто-скиллы, временные баффы, temp XP  
4. `content` — таблицы контента (умения, улучшения, мобы, боссы)  
5. `iap` — интеграция App Gallery + RuStore  
6. `save` — локальный сейв + облачная синхронизация  

### Данные героя (мета)

`classId`, `baseLevel`, `jobLevel`, `stats`, `skillRanks`, `gold`, `crystals`, активные ускорители.

### Данные забега

`mapSeed`, `tempXp`, `activeRunUpgrades`, `hp`, `sp`, `distance` / `bossIndex`. Забег в MVP завершается **смертью**; награда (золото, Base/Job опыт) начисляется при возврате в город. Отдельной кнопки «сдаться» в MVP нет.

## 11. Объём MVP vs позже

### В MVP

- 3 класса, умения, статы Base/Job  
- Endless side-scroller забег  
- Сундуки + дроп + temp XP → выбор усилений  
- Боссы-вехи  
- Узкий город, IAP, русский UI, cloud save  
- App Gallery + RuStore  

### После MVP

- Квесты, районы города, крафт  
- Мультиплеер  
- Скины, battle pass, доп. классы/биомы  
- Доп. языки  

## 12. Критерии успеха MVP

- Игрок за 1 сессию понимает: город → забег → смерть → прокачка → снова в поля  
- Три класса ощущаются по-разному (дальник / маг AoE / танк-саппорт)  
- Есть желание «ещё один забег» за счёт выбора усилений и вечной прокачки  
- Покупка кристаллов/ускорителей проходит в обоих сторах  
- Прогресс не теряется при переустановке (облачный сейв)

## 13. Открытые балансные числа (зафиксировать на этапе реализации)

Числовые формулы (урон скиллов, шансы дропа, кривые Base/Job XP, цены IAP, длительность КД) не зафиксированы в этой спеке намеренно: они калибруются на прототипе забега. Состав систем, контент-списки и границы MVP — зафиксированы.
