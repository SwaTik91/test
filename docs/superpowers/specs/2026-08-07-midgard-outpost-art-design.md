# Мидгард: Аванпост — дизайн графики (арт-пак)

Связано с: `docs/superpowers/specs/2026-08-07-midgard-outpost-design.md`

## 1. Цель

Заменить цветные `RectangleComponent` / `CircleComponent` на пиксель-арт в духе светлого фэнтези Ragnarok Online, чтобы забег и город выглядели как игра, готовая к стор-скриншотам.

## 2. Решения

| Параметр | Выбор |
|----------|--------|
| Объём | Полный визуальный пак |
| Порядок | Сначала **статика**, анимации — отдельной волной |
| Источник | **Гибрид**: AI для героев/боссов/уникальных спрайтов; тайлы/простой UI — готовые или сгенерированные под общий стиль |
| Техника в игре | Flame `SpriteComponent` + PNG в `assets/images/` |
| Размер персонажа | ~**48–64×64** px (босс ~96×96) |
| Scale | Nearest-neighbor, без размытия |
| Ориентация спрайтов | Вид сбоку (side-scroller), лицом вправо по умолчанию |

## 3. Подход

**Спрайт-лист + Flame Sprites:** единый пиксельный look, ассеты как PNG с прозрачностью, подключение вместо placeholder-геометрии. Анимации (`SpriteAnimation`) — волна 2.

## 5. Палитра

- Трава/поля: `#3FA34D` → `#1E5C2A`
- Лес: `#2D6A4F`, тени `#1B4332`
- Земля: `#8B5E34` / `#5C3D1E`
- UI/золото: `#E9C46A`
- Обводка/текст: `#1A1A1A`
- Классы: лучник — зелёный акцент; маг — синий; паладин — белый/золото

Тон: светлое приключенческое фэнтези, не хоррор.

## 6. Пайплайн волны 1

1. **Style bible** — один референс-кадр (герой + моб + земля) на утверждение.
2. **Генерация** спрайтов по списку §4 (прозрачный фон, side view).
3. **Постобработка** — обрезка, resize nearest-neighbor до целевого размера, проверка читаемости силуэта на тёмном/светлом фоне.
4. **Интеграция Flame** — заменить placeholder-компоненты на спрайты; зарегистрировать ассеты в `pubspec.yaml`.
5. **Критерий готовности:** в забеге и городе нет цветных прямоугольников у героя, мобов, босса, сундука, земли; фон биома различим.

## 7. Волна 2 — анимации (после волны 1)

Не входит в критерий готовности волны 1:

- Герои: `idle` / `run` / `jump` / `cast` (по 2–4 кадра)
- Мобы: `walk` / `hurt`
- Сундук: `open`
- Простые VFX вспышки скиллов

## 8. Вне скоупа этого арт-пака

- Финальный магазинный key art / трейлер
- Скины классов
- Полная замена Flutter Material UI города на кастомный pixel UI (допускается гибрид: pixel фон + Flutter кнопки с pixel-иконками)

## 9. Риски

- AI-спрайты могут «плыть» по стилю → обязателен style bible и ручная отбраковка.
- Лицензии готовых тайлов → только ассеты с явной коммерческой/CC0 лицензией или собственной генерацией.
- Слишком детализированные спрайты плохо читаются на телефоне → приоритет силуэту, не микродetалям.
